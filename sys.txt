	  Supplier Stock Monitoring System (SSMS)
Project Overview

The Supplier Stock Monitoring System (SSMS) is a web-based inventory tracking platform developed using Django and PostgreSQL. The system enables suppliers to monitor inventory distributed to customers and their branches in real time by collecting sales data from each branch's existing Point of Sale (POS) system.

Instead of replacing the customer's POS software, the system integrates with it through a lightweight synchronization service installed at each branch. The service automatically retrieves sales transactions from the branch's Microsoft SQL Server database and uploads them to the central web portal whenever an internet connection is available.

This approach provides suppliers with complete visibility of stock levels across all customer branches without requiring customers to change their existing systems.

Objectives

The system aims to:

Track stock supplied to customers.
Monitor stock at individual branches.
Automatically deduct stock based on branch sales.
Display current stock balances in real time.
Monitor branch synchronization status.
Generate inventory and sales reports.
Notify suppliers when stock is running low.
Maintain a complete audit trail of stock movement.

Phase 1 Scope

The initial release should focus on:

User authentication and role management.
Customer and branch management.
Product management.
Stock dispatch to branches.
Windows Sync Service for Microsoft SQL Server.
Django REST API for receiving sales.
Automatic branch stock updates.
Dashboard with inventory and synchronization status.
Reporting (dispatch, sales, and stock balances).
Audit logs and basic alerting.

This provides a solid foundation that can later be extended with mobile apps, predictive stock replenishment, supplier analytics, and integration with additional ERP or accounting systems.
